# Security Policy

OpsGrid is a portfolio project, but security reports are taken seriously.

- **Report privately** using GitHub's "Report a vulnerability" (Security Advisories) on this repository. Please do not open public issues for vulnerabilities.
- Include affected endpoint/component, reproduction steps and impact. Tenant-isolation findings are the highest priority.
- Expect an acknowledgement within 7 days.

Security design: see `docs/security/` (threat model, permission matrix, ASVS 5.0.0 verification), produced during Gate 9.
